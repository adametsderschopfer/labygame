# Office Ceiling Tiles — TextureCan / Tiles 0013

Source: https://www.texturecan.com/details/131/
License: CC0 1.0 Universal, https://www.texturecan.com/terms/
Downloaded 2026-09-20 from the source's 4K maps link.

The material imports original 4K color, DirectX normal and roughness maps.
No pixels have been edited. Inset regions of the 16x16 tile atlas are sampled
to avoid duplicating its rails over the procedural ceiling grid. TextureCan
describes this as a procedural mineral-fiber PBR material, not a photographic scan.

The original `source4k.zip` download is kept locally and ignored by Git: its
119.66 MiB size exceeds GitHub's regular file limit, and this repository's LFS
budget is unavailable. The 4K maps used by the material remain tracked above.
The archive can be downloaded again from the source's 4K maps link if needed.

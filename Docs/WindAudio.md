# Фоновый ветер

Используется выбранная пользователем запись **Calm Wind Outside**, автор dbsound:
https://pixabay.com/sound-effects/nature-calm-wind-outside-426735/

Исходник: `SourceAudio/dbsound-calm-wind-outside-426735.mp3`, предоставлен пользователем. Страница источника указывает Pixabay Content License: https://pixabay.com/service/license-summary/ . Запись включена в игру как часть звукового оформления.

`Scripts/import_wind_audio.py` импортирует MP3 штатным `SoundFactory` Unreal 5.8 в `/Game/Audio/Ambience/S_CalmWindOutside`, включает looping и оставляет громкость ассета равной 1. Runtime `MazeWindAudio` использует множитель **0.4 (40% исходной амплитуды)** и FadeIn 3 секунды; нормализация, дополнительные порывы и процедурный синтез не применяются. Папка `/Game/Audio` включена в cook конфигурацией упаковки.

Это локальное оформление, без игровых правил и нового состояния ECS. `AMazeWorld::BeginPlay` создаёт динамический AudioComponent; `EndPlay` останавливает и уничтожает его. Повторный запуск заменяет прежний компонент, перегенерация геометрии звук не перезапускает. Dedicated server звук не создаёт, клиенты воспроизводят его независимо. Звук не пространственный и не UI sound: следует паузе мира. Меню без паузы не выключает атмосферу.

Отражаемые поля, default subobjects и зависимости модулей не меняются. После Live Coding звук будет создан при следующем BeginPlay лабиринта. Play и тесты агентом не запускаются; слуховая оценка остаётся пользователю.

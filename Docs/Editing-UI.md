# Редактирование интерфейса

После сборки новых C++-классов и открытия редактора модуль `labyEditor`
создаёт недостающие ассеты в `Content/UI`. Существующие файлы не перезаписываются.
Первое создание отмечается в Output Log строками `Laby editable UI created`.
Сохранённые `.uasset` нужно хранить вместе с проектом в системе контроля версий.

В Content Browser откройте папку `UI`, затем нужный Widget Blueprint и вкладку Designer:

| Ассет | Назначение |
| --- | --- |
| WBP_HUD | Новый HUD: прицел, индикаторы состояния, сообщения и отдельная отладочная карта F7 |
| WBP_ExplorationMap | Игровая мини-карта с компасом и открытая карта M |
| WBP_MainMenu | Главное меню |
| WBP_PauseMenu | Меню паузы |
| WBP_Settings | Видео, управление и параметры HUD/камеры |

Перемещайте элементы, меняйте размеры, отступы, Anchors, шрифты, цвета,
тексты кнопок и изображения. Затем нажмите Compile и Save.
Изменения видны при следующем создании виджета: меню можно закрыть и открыть,
HUD — пересоздать при следующем запуске игры. Не требуется пересборка C++ для оформления.

## Связь оформления с кодом

Сохраните родительский класс `MazeHUDWidget` для HUD и `MazeMenuWidget` для меню.
Не переименовывайте ассеты: контроллер и HUD загружают их из `/Game/UI`.
Папка добавлена в `DirectoriesToAlwaysCook`, чтобы интерфейс попал в сборку игры.

Имена следующих элементов используются кодом. Их можно перемещать и оформлять,
но при переименовании связь с данными или действием исчезнет:

| Элементы | Тип / роль |
| --- | --- |
| ResumeButton, NewGameButton, SettingsButton, BackButton, QuitButton, ResetButton | Button: действия меню |
| SensitivitySlider | Slider: чувствительность |
| SensitivityText | Text Block: значение чувствительности |
| HUDContent | Контейнер всего HUD; скрывается при открытии меню |
| VitalsPanel | Контейнер здоровья и выносливости |
| HealthText, StaminaText | Text Block: значения из ECS |
| HealthBar, StaminaBar | Progress Bar: заполнение из ECS |
| VersionText, SessionText, DeveloperHint | Text Block: версия, сеанс, подсказка разработчика |
| DeathPanel, ExitPanel | Контейнеры сообщений; по умолчанию Collapsed |
| ExitText | Text Block: номер достигнутого выхода |
| MinimapPanel | Контейнер отладочной карты, переключаемый F7 в development-сборках |
| MinimapBounds, FullMapBounds | В WBP_ExplorationMap: границы игровой мини-карты и открытой карты |

Runtime обновляет текст значений и заполнение полосок. Для смены цветов выносливости
используйте `Stamina Color` и `Exhausted Color` в Class Defaults HUD.
Цвет здоровья задаётся на `HealthBar` в Designer.

Элемент `Minimap` имеет нативный класс `MazeMinimapWidget`. Его можно перемещать и
масштабировать через контейнер `MinimapPanel`, менять цвета в категории `Maze | Style`.
Это отладочная карта F7; игровой вид карты находится в `WBP_ExplorationMap`.
Линии лабиринта рисуются из готовых ECS-данных во время игры; в Designer они не отображаются.
Для оформления сообщений о смерти/выходе временно включите их Visibility в Designer,
затем верните Collapsed; во время игры видимость управляется состоянием ECS.

Логика здоровья, выносливости, генерации, прогресса и сеанса остаётся в Mass ECS.
Виджеты читают снимки данных и передают действия контроллеру. Не добавляйте в них
второе независимое состояние игры. Обработчики стандартных кнопок подключаются
нативным классом: дублировать те же действия через Blueprint OnClicked не нужно.

## Первое подключение

Для этой миграции нужен закрытый редактор и полная сборка `labyEditor Win64 Development`:
добавлены UMG, новые отражаемые классы и editor-модуль. После сборки откройте проект
обычным способом и дождитесь создания четырёх ассетов. Live Coding применяется
к последующим совместимым правкам C++, но не заменяет эту первоначальную сборку.

Editor-модуль не создаёт файлы во время cook или других commandlet-запусков.
Перед упаковкой проекта ассеты должны быть созданы и сохранены обычным редактором.

## Автоматический Live Coding

Editor-модуль наблюдает за сохранениями файлов `Source` раз в секунду.
После изменения существующего `.cpp` и пяти секунд без новых изменений он
запрашивает Live Coding через API редактора. Параллельные компиляции не запускаются;
изменения во время сборки остаются для следующего запроса. Ошибка сборки не вызывает
бесконечных повторов: новый запрос появляется после следующего сохранения.

Изменение заголовков, build rules, `.uproject`, добавление или удаление файлов
приостанавливает автоматические запросы до проверки совместимости. Это не означает,
что каждый заголовок требует перезапуска: совместимые изменения можно применить
ручным Live Coding. Изменения зависимостей требуют полной сборки с закрытым редактором.

Команды Output Log:

- `laby.AutoLiveCoding 0` — отключить автоматические запросы.
- `laby.AutoLiveCoding 1` — включить их для последующих сохранений.
- `laby.AutoLiveCodingDelay 8` — изменить задержку на восемь секунд (минимум две).

После проверки заголовков отключите автокомпиляцию на пару секунд и включите снова,
чтобы снять приостановку. Обычный Ctrl+Alt+F11 продолжает работать независимо.
Автокомпиляция не запускает Play, не перезапускает редактор и не вызывает Build.bat.
Для первоначального подключения самого наблюдателя также требуется полная сборка.

## Дуговое игровое меню

`ShowNetworkMenu` теперь выбирает `WBP_MainMenu`, `WBP_PauseMenu` или `WBP_Settings`
вместо временного списка Slate. Состояние меню остаётся в ECS; фокус и очистка ввода —
в контроллере. Возврат в главное меню использует существующий транспортный `Leave`.

Пункты размещены по полукругу на матовых серых поверхностях и слегка повёрнуты.
Наведение использует стандартные состояния UButton. Макет 1920×1080 масштабируется
целиком через ScaleBox. Четыре текстуры `/Game/UI/Arc` запечены редактором;
дополнительных игровых камер, SceneCapture, blur и runtime render targets нет.
HUD пересобран: фигурная панель с тонкими индикаторами, новые сообщения, прицел и
подсказки. Отладочные seed/размер/подсказка показываются только вместе с картой F7.
Верхняя лента компаса удалена; стороны света и маркер взгляда находятся на краях
игровой мини-карты. Мини-карта и большая карта используют единое новое оформление.

Настройки:

- Видео: общий уровень качества, тени, FPS, масштаб рендера и VSync. Владелец —
  `UGameUserSettings` UE 5.8; используются ApplyNonResolutionSettings и SaveSettings.
  Разрешение и режим окна этот экран не переключает.
- Управление: чувствительность и инверсия Y. Показана фиксированная раскладка;
  переназначение клавиш не реализовано.
- Игра: FOV, компас, центральная точка, компактные показатели и покачивание камеры.
  Исходный FOV — прежние 95°; отладочная камера от третьего лица не затрагивается.

Контролы хранят черновик. Только «Применить» сохраняет параметры; «Исходные» меняет
черновик, «Назад»/Esc его отбрасывает. Чувствительность по-прежнему принадлежит
UMazePreferences, остальные параметры представления — секции Maze.InterfacePreferences
в GameUserSettings.ini. Они локальны для установки и не реплицируются.

Новые имена привязок: MainMenuButton, VideoTabButton, ControlsTabButton, GameTabButton,
ApplyButton; SettingsPages (WidgetSwitcher); QualityCombo, ShadowsCombo, FrameLimitCombo;
RenderScaleSlider/Text, FieldOfViewSlider/Text; VSyncCheck, InvertYCheck, CompassCheck,
CrosshairCheck, CompactHUDCheck, CameraMotionCheck и SettingsStatus.

Редакторский исходник — `Source/labyEditor/Private/UI/MazeArcUIAssets.cpp`.
`laby.UI.ApplyArcStyle` явно пересоздаёт три меню и HUD, обновляет границы игровой карты.
Идентификаторы переменных Widget Blueprint синхронизируются через API UE 5.8.
Команда не вызывается автоматически и не работает во время Play. Перед повторным
вызовом сохраните собственные правки меню и HUD: их макеты будут заменены. Ассеты до этой итерации скопированы
в `Saved/UIBackups/BeforeArc-20260920-031220`.
`laby.UI.PreviewArcStyle` выводит статические снимки меню и Designer-снимки карты в `Saved/UI/ArcPreview`
без игровых миров и Play; FWidgetRenderer используется только редакторским кодом.

Стандартных UMG/Slate, brush states, Render Transform и ScaleBox достаточно для
этой композиции. CommonUI не добавляется: многоплатформенная маршрутизация действий
пока не нужна. RetainerBox и дополнительный проход искажения также не требуются.

## Карта и компас

`UMazeExplorationMapWidget` читает готовую топологию, позицию, поворот камеры и маску
исследования из существующих источников. `MazeMapPaint` — синхронный рендерер Slate,
без UObject, сущностей, таймеров и сохранённого состояния. Входные указатели/array views
живут только до окончания одного paint; совпадение maze handle и revision проверяется.
Неисследованные клетки, провалы и выходы не раскрываются новым оформлением.

Север соответствует -Y, восток +X. Карта не вращается; N/E/S/W стоят по краям,
а янтарный шеврон на рамке показывает направление камеры. Переключатель компаса
в настройках управляет этой индикацией. Размер мини-карты — 312×312 логических
единиц; положение настраивается через MinimapBounds. FullMapBounds задаёт границы
большой карты. Перемещение мышью, масштаб вокруг курсора, Home и M/Esc сохранены;
центр масштабирования учитывает расположение FullMapBounds.

Designer-предпросмотр не создаёт лабиринт и не запускает gameplay: показывает рамку,
сетку и пример маркера. Команда PreviewArcStyle экспортирует меню, HUD, большую карту
и Minimap.png; в большом кадре явно указано «Предпросмотр оформления».

# Интернет-мультиплеер LABY

## Что реализовано

Listen server через Online Subsystem EOS и P2P-транспорт EOS. Хост создаёт комнату,
получает код из 10 символов и копирует его кнопкой. Остальные входят через Epic Games
и находят EOS lobby по коду. Все используют одну версию игры и один EOS deployment.

В комнате максимум 4 участника, включая хоста. До запуска нет игровых персонажей.
Список и метка хоста реплицируются из Mass ECS через GameState. Только хост может
начать, даже один. После запуска сервер создаёт персонажей на четырёх разнесённых
позициях в центральной клетке. Топология одинакова по seed, выход ровно один.
Персонаж визуально состоит из цилиндра и двух полусфер (капсула).

После запуска вход новых игроков закрыт. Из комнаты и из меню игры можно выйти.
Выход хоста завершает соединение: гости возвращаются в главное меню. Миграция
игрового хоста и повторное подключение к уже начатой игре не реализованы.
Меню игрока не останавливает сервер. Здоровье, выносливость и достижение выхода
считает серверный ECS; владельцу реплицируются снимки для HUD. CharacterMovement
отвечает за сетевое движение, локальный ввод используется для предсказания.

## Первичная настройка EOS (обязательна)

Проекта EOS на момент реализации ещё нет. Без него реальные интернет-комнаты
создавать нельзя. Фиктивные идентификаторы и ключи в конфигурацию не добавлены.

1. В https://dev.epicgames.com/portal создайте организацию/продукт LABY,
   выберите sandbox и deployment для разработки.
2. Создайте EOS Client и подходящую клиентскую политику с разрешениями для
   аутентифицированных пользователей, Connect, Lobbies и P2P. Не используйте
   серверные административные учётные данные в игре.
3. Настройте приложение Epic Account Services, разрешение Basic Profile и
   свяжите EOS Client с приложением. В режиме разработки добавьте тестировщиков
   в организацию или разрешённую группу доступа к sandbox. Используйте разные
   Epic-аккаунты на разных компьютерах.
4. В Unreal: Project Settings → Plugins → Online Subsystem EOS → Artifacts
   добавьте artifact. Заполните Product ID, Sandbox ID, Deployment ID, Client ID,
   Client Secret. Задайте Artifact Name, например LabyDevelopment, и такой же
   Default Artifact Name. Сохраните настройки. Если редактор требует Encryption
   Key, используйте 64 шестнадцатеричных символа по инструкции Epic.
5. Use EAS и Use EOS Connect включены в DefaultEngine.ini. В игре при создании
   или входе в комнату открывается Account Portal для входа в Epic Games.
   Сервис должен разрешать доступ обоим тестовым аккаунтам.
6. После добавления artifact перезапустите редактор. Для внешней проверки
   используйте одинаковые упакованные Development-сборки на двух компьютерах
   в разных сетях. Отдельный выделенный сервер и проброс порта не требуются.
   Брандмауэр должен разрешать игре исходящие соединения EOS.

Официальная документация для UE 5.8:
https://dev.epicgames.com/documentation/unreal-engine/online-subsystem-eos-plugin-in-unreal-engine

## Применение изменений

Нужна обычная сборка с закрытым редактором, затем запуск редактора заново:
добавлены модульные зависимости, GameInstance/GameState, RPC, отражаемые поля и
новые default subobjects персонажа. Эти изменения не предназначены для Live Coding.
Редактор автоматически не закрывался. Сборка, Play и автоматические тесты агентом
не запускались. Форматирование выполнено Scripts/Format-Code.ps1.

Пример команды из корня проекта после закрытия редактора:

```powershell
& 'C:/Program Files/Epic Games/UE_5.8/Engine/Build/BatchFiles/Build.bat' labyEditor Win64 Development '-Project=C:/ue_prj/laby/laby.uproject' -WaitMutex
```

## Ручная проверка пользователем

- Создать комнату; код копируется и вставляется без изменений.
- Войти с другого Epic-аккаунта через другую сеть; оба видят список и хоста.
- До запуска никто не может ходить; начать может только хост.
- Проверить запуск с 1, 2 и 4 участниками, отказ пятому.
- Игроки появляются рядом без пересечения; видят капсулы друг друга.
- У всех одинаковые стены и единственный выход; проверить бег и прыжки с задержкой.
- Открытие меню у хоста/гостя не останавливает остальных.
- Выход гостя обновляет список; освободившееся место доступно до начала игры.
- Выход/аварийное закрытие хоста возвращает гостей в меню с сообщением.
- Проверить неверный код, отмену входа Epic, недоступность сети, повторное создание
  и повторный вход после выхода.

Транспортная интеграция и сетевое движение требуют проверки после настройки EOS;
успешная интернет-сессия пока не подтверждена.
